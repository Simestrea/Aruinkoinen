快速上手

aurinko CLI · 项目脚手架 · v0.3.5

工作流程
▸

标准流程

概览

从零开始，六步跑起来一个可发布的项目。

命令
# 1. 创建项目
aurinko create

# 2. 创建角色
aurinko create Alice

# 3. 编辑 characters/Alice/Alice.hpp

# 4. 导入字体（非 ASCII 必须）
aurinko addfont C:/Windows/Fonts/msyh.ttc

# 5. 编译
aurinko update

# 6. 运行
./release/game.exe
依赖
  • g++，需 C++20 协程（MinGW-w64 GCC 13+ / Linux GCC 12+）
  • raylib，能链接到 -lraylib
create
▸

aurinko create

命令

在当前目录创建空项目。

交互
画布宽度: 800
画布高度: 450
生成
路径说明
project.txt画布尺寸（"宽 高"）
characters/角色目录（空）
fonts/字体目录
build.txt附加编译参数
globals.hpp全局变量容器
注意
当前目录已有 project.txt 时拒绝执行，不覆盖。
create <角色名>
▸

aurinko create <角色名>

命令

创建新角色：精灵图 + 配置 + 剧本模板。

交互
图片路径: /path/to/sprite.png     （支持拖拽文件到终端）
缩放倍数 (默认 2.0): 2
精灵图帧数 (默认 10): 10
每帧持续秒数 (默认 0.15): 0.15
场景编号 (默认 0): 0
生成
characters/Alice/
├── Alice.hpp      # 剧本（你改这个）
├── Alice.png      # 精灵图
└── config.txt     # 配置
命名约定
函数名必须是 <角色名>Fun。
characters/char1/ → 函数名 char1Fun。
addfont
▸

aurinko addfont <路径> [名字]

命令

把 TTF / TTC / OTF 字体复制到 fonts/。

示例
aurinko addfont C:/Windows/Fonts/msyh.ttc

update
▸

aurinko update [参数...]

命令

扫描角色 → 生成 index.cpp → 调 g++ → 打包 release/。

流程
1. 读取 characters/*/config.txt
2. 检查角色 .hpp 没有引用被禁内部符号
3. 解析 Task / Clone 函数签名
4. 生成 index.cpp
5. 调 g++ 编译成 game.exe
6. 打包 release/
参数
参数说明
-d / --debugdebug 编译（保留终端，跳过 release/）
-lxxx追加链接库
-Ixxx追加 include 路径
-Dxxx追加宏定义
build.txt
项目根目录的 build.txt，每行一条参数，# 开头注释，自动拼接到编译命令。
release 隐藏终端
release 编译加 -mwindows，双击不弹终端；debug 不加。

等待
▸

co_await aur::WaitFor{ 秒数 } / aur::WaitNextFrame{}

等待器

让协程挂起指定时间或挂起到下一帧。

示例
c.Say("Line A", 1.5f);
co_await aur::WaitFor{ 1.5f };
c.Say("Line B", 1.5f);

while (true) {
    if (IsKeyDown(KEY_D)) c.ChangeX(5.0f);
    co_await aur::WaitNextFrame{};   // 必须加！
}
关键
while(true) 里必须有 co_await，否则这一帧永远结束不了。
Clone
▸

aur::Clone

克隆体脚本

带 Clone 的函数不会自动跑，需要 ctx.scene.Spawn() 手动挂载。

示例
inline aur::Clone AliceClone(aur::Character& c, aur::Context& ctx) {
    c.Say("clone", 1.0f);
    co_await aur::WaitFor{ 1.0f };
    c.Destroy();
    co_return;
}

if (IsKeyPressed(KEY_SPACE))
    ctx.scene.Spawn(c, c.GetScene(), AliceClone);
注意
克隆体脚本里调 Destroy() 后立刻 co_return，不要再访问该角色。
完整示例
▸

Alice 的剧本

示例

一个能跑的完整角色脚本。

代码
#pragma once
#include <aurinko/character.hpp>
#include <aurinko/coroutine.hpp>
#include <aurinko/scene.hpp>
#include <aurinko/text.hpp>
#include <aurinko/context.hpp>
#include "globals.hpp"

inline aur::Task AliceFun(aur::Character& c, aur::Context& ctx) {
    int W = ctx.screen.GetVirtualWidth();
    int H = ctx.screen.GetVirtualHeight();

    c.GoToXY(W / 2.0f, H / 2.0f);
    c.Say("Hello", 2.0f);
    co_await aur::WaitFor{ 2.0f };

    while (true) {
        if (IsKeyDown(KEY_D)) c.ChangeX(200 * GetFrameTime());
        if (IsKeyDown(KEY_A)) c.ChangeX(-200 * GetFrameTime());
        c.BounceOffEdge(W, H);
        co_await aur::WaitNextFrame{};
    }

    co_return;
}

struct aur::Context

结构体

打包了所有可安全暴露给脚本的全局资源。通过函数参数 ctx 访问。

字段
字段类型用途
ctx.sceneSceneManager&场景管理器
ctx.schedulerCoroutineScheduler&协程调度器（一般不用直接碰）
ctx.screenVirtualScreen&虚拟屏幕（查尺寸、坐标换算）
ctx.texturesTexturePool&纹理池
ctx.fontsFontPool&字体池
鼠标坐标
▸

ctx.screen.GetVirtualMousePosition()

必备

把真实鼠标坐标换算成虚拟画布坐标。

规则
UI 位置是虚拟坐标（0..W, 0..H）。鼠标坐标必须用这个函数。
不要用 GetMousePosition()——它是窗口像素坐标。
示例
Vector2 m = ctx.screen.GetVirtualMousePosition();
if (CheckCollisionPointRec(m, myRect)) {
    // 命中
}

VirtualScreen

init.hpp · 虚拟画布 + 窗口缩放 · 通过 ctx.screen 访问

生命周期
▸

Init(int vWidth, int vHeight, const char* title, bool resizable = true)

初始化

初始化窗口和虚拟画布。程序启动时调用一次。

参数
参数类型说明
vWidthint虚拟画布宽度
vHeightint虚拟画布高度
titleconst char*窗口标题
resizablebool是否允许拖拽窗口边缘。默认 true
说明
内部创建：窗口 + 渲染目标纹理（尺寸 = 窗口尺寸）+ Camera2D。绘制在 Begin() 到 End() 之间进行，坐标是虚拟画布坐标。
Init 由 index.cpp 自动调用，脚本里不要碰。
▸

Close()

关闭

卸载渲染纹理并关闭窗口。

说明
由主循环在退出时调用。显式释放 GPU 资源。
渲染
▸

Begin(Color clearColor = RAYWHITE)

渲染

开启绘制到虚拟画布，指定清屏色。

说明
内部会：检查窗口尺寸是否变化 → 重建纹理 → 清屏 → 进入 Camera2D 缩放模式。所有绘制在虚拟坐标系进行。
脚本里禁止调用。帧由 index.cpp 主循环控制。
▸

End()

渲染

结束虚拟画布绘制，1:1 贴回窗口。

说明
退出 Camera2D → 退出纹理模式 → 把纹理 1:1 贴到窗口。因为纹理尺寸 = 窗口尺寸，不再二次缩放，所以字和图形都清晰。

说明

FontPool（通过 ctx.fonts 访问）

字体池

同一字体文件只加载一次。自动包含 9000+ 常用码点。

方法
方法说明
Font Load(key, path, baseSize = 64)按 key 显式加载
Font GetOrLoad(key)获取或懒加载
bool Has(key)是否已缓存
void UnloadAll()卸载所有字体
加载的码点
ASCII + 希腊字母 (0x0370-0x03FF) + 通用标点 (0x2000-0x206F) + 上下标 (0x2070-0x209F) + 箭头 (0x2190-0x21FF) + 数学运算符 (0x2200-0x22FF) + CJK 标点 (0x3000-0x303F) + 全角字符 (0xFF00-0xFFEF) + CJK 常用汉字 (0x4E00-0x9FA5)。
aur::Text 会自动 GetOrLoad，一般不用手动调。baseSize 越大，缩放时越清晰，但显存占用越大。
